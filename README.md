# 子平纳音·体用法 技能包

> 以子平为体、纳音神煞为用的八字断命总纲技能。

「子平纳音·体用法」把《子平真诠》的**月令格局**体系与《李虚中命书》的**纳音神煞**体系合流，构成一套主次分明的断命流程。结论来自古籍规则匹配，用于命理研究与内容创作参考。

## 体用融合思路（核心）

两者的主次关系是——**以子平为体，以纳音神煞为用**：

- **体（子平）：解决「有没有」和「能不能」。**
  先看**日干与月令**的关系（得时失时、党众助寡、身强身弱），再拆**十神组合**（财官印食透藏、通根与否），最后定**格局成败与用神喜忌**。这一步确定命局里「有没有财官、能不能成格」。
- **用（纳音神煞）：修饰「是什么感觉」。**
  在格局定性之后，用**纳音取象**（如钗钏金藏锋、城头土筑基）与**神煞**（天乙贵人、文昌、魁罡、禄马）补足人的气质、性情、际遇的质感，只做润色，不改判局。
- **铁律（主次不可倒置）**：格局贵贱一律以子平为准，纳音神煞**绝不充当格局判据**，也不得对子平结论翻案；体用冲突时以体（子平）为断。

一句话：**先吃透日干与月令、把十神组合看透，定下旺衰与格局；再用纳音修饰这份「感觉」**——主次分明，融而不混。

## 输入要求（断命必问）

1. **完整四柱八字**（如「甲子 乙亥 庚戌 癸未」）；
2. **性别**（男 / 女，定大运顺逆）。

> 缺任一项不臆造、不默认，先问清补齐。

## 推演大运的前置要求

**AI 推算起运岁数不精准**（须节气交节日时精确计算）。要推演大运/流年时，请用户提供**起运年岁**（如「8岁起运」）后再推演；未提供时只断静态格局。

## 安装

1. 打开你的 AI 助手的「技能 / 插件 / Skills」入口。
2. 点「导入 / Import」，选中 `技能包/` 里的**技能文件夹**（`子平纳音体用法`）。
3. 导入后启用即可。技能含 `SKILL.md` 主文件 + `references/` 速查参考，一次导入整个文件夹。

## 使用示例

```
你：帮我排盘甲子 乙亥 庚戌 癸未，男的。
助手：先以子平定旺衰格局——庚金生亥月失令，财旺身弱、丁火官星藏而不透……再以纳音神煞取象修饰性情……
```
