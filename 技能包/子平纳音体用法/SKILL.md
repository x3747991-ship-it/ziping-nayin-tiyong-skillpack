# 子平纳音·体用法 · 以子平为体、纳音神煞为用

「子平纳音·体用法」以《子平真诠》（清·沈孝瞻原著）为体，融合《李虚中命书》纳音、神煞为用，构成一套**主次分明**的断命流程。

**体（子平法）**：以「月令格局 ＋ 日干旺衰 ＋ 十神组合 ＋ 用神喜忌」为核心，解决命局「**有没有**」（有无财官印食等资源贵气）与「**能不能**」（这些资源能否为日主所用、格局能否成立）两大问题。

**用（纳音、神煞）**：以「纳音取象 ＋ 神煞层次」为辅助，解决命局「**是什么感觉**」——即格局既定之后，这个命的气象、性情、气质、质感如何。

**主次铁律**：先定体，后取用。**格局成败、贵贱高下，一律以子平法（月令格局＋旺衰）为准**；纳音神煞只做修饰与层次微调，**绝不倒过来用纳音神煞去推翻或裁定格局的成与败**。

## 三、核心方法论（三层追问，主次分明）

断一个命，按「**有没有 → 能不能 → 是什么感觉**」三步递进，绝不跳步、绝不倒置：

### 3.1 有没有（体 · 第一步）
看四柱**有没有**值得谈的「资源与贵气」：财、官、印、食（及煞、伤、刃、劫等十神）是否**透干、通根、成象**。
- 月令是当旺之气的源头，先看月令藏干透出何神、十神为何。
- 命中财官印食**全无根气**，则先谈「无」，再谈其余。

### 3.2 能不能（体 · 第二步，最重）
这些资源**能不能为日主所用、格局能不能成立**：
- **日干旺衰**：得时（月令当令）为旺、失时为衰；党众（通根比劫印）为强、助寡为弱。二者合看，有四态——旺而强、旺而弱、衰而强、衰而弱。
- **月令取格**：以日干配月令地支生克，定格局；财官印食为**善用神须顺用**（生之护之），煞伤劫刃为**恶用神须逆用**（制之化之）。
- **格局成败**：看顺逆是否得宜、有无刑冲破害成败救应，论「成格 / 破格 / 半格」。
- **用神喜忌**：扶抑、病药、调候、专旺、通关五法定用，定喜神忌神。

### 3.3 是什么感觉（用 · 第三步）
格局既定、贵贱已分之后，才用**纳音、神煞**修饰：
- **纳音取象**：看各柱（尤其日、年、胎元）纳音五行之象，修饰日主的**性情、气质、形貌、度量**——是金之刚直、水之沉潜、木之柔懦、火之崇礼、土之厚重，同是「正官格」，纳音不同则「感觉」不同。
- **神煞辅助**：贵人、禄马、天月德、文昌等，在格局高下既定后做**层次微调**（如「成格」之上再「带贵」更美），**不改变格局成败的定性**。

## 四、断命七步流程

> **输入必备（强制）**：接受断命诉求后，**必须先向用户确认两样输入**——
> 1. **完整四柱八字**（如「甲子 乙亥 庚戌 癸未」）；
> 2. **性别**（男 / 女，用于定大运顺逆）。
> 凡缺其一，**不得臆造或默认可排**，先追问补齐。
>
> **推演大运的前置要求**：若用户要求推演大运/流年，应在排盘之外，**请用户提供「起运年岁」**（如「8岁起运」），再据以推演。**AI 推算起运岁数不精准**（须节气交节日时精确计算），不得自作主张推算起运数；用户未给起运年岁时，只断静态格局，并礼貌说明「提供起运年岁后可精确推运」。

**第一步 · 排盘**
由出生时间排四柱（年、月、日、时），月柱以节气为界；标注各支**藏干**。凡数据缺失（日期/时辰不明），**须先向用户确认，不得臆造干支**。

**第二步 · 判日干旺衰（得时 / 失时 ＋ 党众 / 助寡）**
- 月令是否生扶日干（得时、当令）；比劫印绶是否通根成党（党众）。
- 得时「旺」看是否党众成「强」；失时「衰」看是否通根成「强」。
- 通根重轻：长生禄旺 > 余气 > 墓库；**月令之支为根最重**；干多不如支重。

**第三步 · 定月令格局（十神取格）**
以日干配月令地支藏干，定十神、定格（正官格、七杀格、财格、印格、食神格、伤官格、阳刃格、建禄月劫格、外格等）。辨**善用神顺用、恶用神逆用**。

**第四步 · 取用神喜忌 ＋ 判格局成败**
五法（扶抑/病药/调候/专旺/通关）定用神与喜忌；查刑冲破害、会合解法，判「成格 / 破格 / 因成得败因败得成」。**此步定「有没有、能不能」的最终结论**。

**第五步 · 断体（结论主体）**
由第二至四步，给出：日主旺衰、格局高低、用神喜忌、财官印食之有无与成败。**这是断命的正文与结论骨架**。

**第六步 · 查神煞辅助层次**
在体既定后，查天乙贵人、干禄、驿马、天德月德、文昌等，做层次微调（得地则锦上添花、失地则减色），**不改格局定性**。

**第七步 · 纳音取象修饰（是什么感觉）**
看日/年/胎元纳音五行，修饰性情、气质、形貌、度量与六亲亲缘之「质感」；与旺衰格局相印证，给出「格虽贵而其气…」「虽有财官而气象…」的修饰性结论。纳音与子平定断冲突时，**以子平为准，纳音仅作观感补充**。

### 5.2 断语结构（「体 → 用」分明）

1. **旺衰**：日干得时/失时、党众/助寡，定四态之一。
2. **格局**：月令取何格、善用顺用/恶用逆用，格局成/破。
3. **用神喜忌**：用神为何、喜神忌神各为何。
4. **有没有/能不能**：财官印食有无根气、能否为用（此为核心结论）。
5. **神煞层次**：贵人禄马天月德得地与否的微调。
6. **纳音取象（是什么感觉）**：性情气质形貌的修饰性描述。
7. 末尾可点明**行运喜忌**（顺用逆用在大运流年的吉凶取向）。

### 5.3 表达原则

- **体用分明**：格局贵贱的结论必须出自子平（旺衰＋格局＋用神）；纳音神煞只做修饰，不得充当格局判据。
- **说明依据**：结论可回溯到具体干支/月令/十神/纳音，避免空泛。
- **忠实古籍**：断语以《子平真诠》原文意象为体，以《李虚中命书》纳音神煞取象为用；古籍未覆盖的现代事项，如实说明「原文无此断」。
