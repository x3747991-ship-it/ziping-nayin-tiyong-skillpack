# 子平法 · 用：纳音神煞辅助（取象修饰）

> 本篇为「子平法技能包」之**用**，据《李虚中命书》纳音、神煞蒸馏。
> 用途：在「体」（旺衰格局）定案之后，解决命局「**是什么感觉**」——性情、气质、形貌、度量之质感，及贵人禄马等层次微调。
> **铁律：本篇不裁定格局成败、贵贱高下；一切定性结论以 `子平法_旺衰十神格局用神.md` 为准。**

---

## 一、定位与边界（为何只是「用」）

| 层 | 回答的问题 | 出何处 | 可否定贵贱 |
|---|---|---|---|
| **体**（子平） | 有没有、能不能 | 月令格局 / 旺衰 / 十神 / 用神 | **是，唯一依据** |
| **用**（纳音神煞） | 是什么感觉 | 纳音取象 / 神煞 | **否，仅修饰与微调** |

- 子平断「正官格成、身旺任官，贵」→ 纳音只在其上加一句「其气如何」：是刚直锋芒、还是沉潜内敛、还是木秀水润。
- **当纳音神煞与子平分铨不合时，以子平为准**。例：子平断身弱无根、格局破败，纵命带天乙贵人，仍以「虽带贵而不成格」论，贵人只作「破格之上稍有体面」的微调，不得翻案称贵。

## 二、纳音取象：修饰性情气质（「是什么感觉」的主体）

### 2.1 取象三层次

1. **层次一 · 纳音五行**：日/年/胎元纳音的五行（金木水火土），定性情基调。
2. **层次二 · 纳音具象**：六十花甲纳音之名象（海中金、剑锋金、长流水、松柏木……），定气质质感。
3. **层次三 · 五行多寡**：全命局纳音五行的多寡轻重，定性情偏颇。

> 例：正官格吉命之人，日柱纳音「剑锋金」者，气质刚毅有断、清华贵气外露；「海中金」者，金溺水下、韬光内敛，富贵藏而不露。同一格局，**「感觉」迥异**，此即纳音取象之用。

### 2.4 取象重点位置

- **日柱纳音**：最贴身，主「才器度量、形貌」之取象（人元=身）。
- **年柱纳音**：主「祖上根基、出身气象」；**胎元纳音**：主「先天禀赋」。
- 命带**自生自旺**纳音者，取象上主「精气自足、气象亨通」；休囚死绝者主「气薄、晚发」。
  - 金：辛巳自生、癸酉自旺；木：己亥自生、辛卯自旺；水：甲申自生、丙子自旺；火：丙寅自生、戊午自旺；土：戊申自生、庚子自旺。

## 三、神煞辅助：层次微调（不可改定性）

### 3.1 天乙贵人（三命最吉之神）
| 日/年干 | 贵人 |
|---|---|
| 甲戊庚 | 丑未 |
| 乙己 | 子申 |
| 丙丁 | 亥酉 |
| 壬癸 | 卯巳 |
| 六辛 | 寅午 |

- 命带天乙贵人，且**乘旺气、不犯空亡、支干相合**者，主荣名早达、官录易进——在子平「成格」之上，更添「有贵气」的修饰。
- **贵合**（干合于贵，如甲得己丑）＝官位穹崇；**贵食**（食神在贵，如甲食丙得丙寅）＝禄丰足。
- **无德值空亡则至死不贵**——故贵人须与旺衰格局相参，方为「有用之贵」。

### 3.2 禄马 · 天月德 · 文昌（辅助层次）
- **干禄**（甲禄寅、乙禄卯、丙禄巳、丁禄午、戊禄巳、己禄午、庚禄申、辛禄酉、壬禄亥、癸禄子）：禄主衣食受用，得地为「有禄」的层次修饰。
- **驿马**（申子辰马寅、寅午戌马申、巳酉丑马亥、亥卯未马巳）：主迁移、变动、远行、升腾之象。
- **天德、月德**：主逢凶化吉、德性宽厚之修饰。
- **文昌、学堂、词馆**：主文秀聪明之修饰（与食伤泄秀之聪明相印证）。

### 3.3 神煞用在「微调」而非「翻案」
- 子平断「贵格」+ 天乙贵人得地 → 修饰为「贵而带福」。
- 子平断「贱格」+ 天乙贵人 → 修饰为「虽贱而稍有体面/近贵之缘」，**不得翻案称贵**。

## 四、体用融合流程（定体后如何取象）

### 4.1 融合口诀
1. **先体**：旺衰 → 格局 → 用神喜忌 → 有没有/能不能（定案）。
2. **后用**：在定案之上，加「观感」层——纳音取象修饰性情气质，神煞做层次微调。
3. **表达分两段**：先结论（体），后修饰（用），泾渭分明。

### 4.2 示意（以「甲子 乙亥 庚戌 癸未」男命为例）
- **体（子平定案）**：庚金生于亥月，失令；地支戌未皆有土金余气，日主有根而偏弱——论「身弱」；月令亥中甲木偏财、壬水食神透出……格局如何、有无财官、能不能任，**在体中断**（此例结论见排盘实测）。
- **用（纳音取象）**：四柱纳音为海中金—山头火—钗钏金—杨柳木。日柱庚戌钗钏金「钝弱成用之金，火轻金重，魁罡相乘则休逸，忌木火极」；年柱海中金「金溺水下，韬光」——**取象为**：才具如钗钏之器，成用于雕琢之后，气质偏于内敛而不外扬，非叱咤风云之象，而是「藏锋待用」之感。
- **用（神煞）**：庚日论贵人……（据实际查填补），在体既定后做「有无贵气、禄马」的层次微调。

> 注：上例取象部分仅示范「体→用」的写法与次序，具体断语须以实际排盘为准。
